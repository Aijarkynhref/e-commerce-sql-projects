# E-commerce SQL Projects

This repository contains practical SQL solutions for e-commerce data management.

## Project 1: Catalog Data Cleaning (Legacy Product Filtering)

**Task:** The database contained temporary or invalid entries starting with the "HH" barcode prefix. I needed to isolate valid legacy products and remove the noise.

**Solution:** Developed a SQL script using `LIKE` patterns to filter the product catalog by barcode prefixes.

**Business Impact:** Improved catalog accuracy and prevented errors in inventory synchronization.
